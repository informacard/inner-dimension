# Inner Dimension

Source snapshot 2.6.9 for Minecraft 1.21.11 / Fabric, Java 21.

## Build

This project uses Minecraft intermediary names. Provide an intermediary-mapped Minecraft 1.21.11 jar, Fabric Loader, relevant Fabric API modules and dependency jars in `libs/`, then run `./build.ps1`. Dependency versions are listed in `resources/fabric.mod.json`. Minecraft and third-party mod binaries are not redistributed.

For Inner Dimension, build Non Player Plushie first and include its jar among the dependencies.

This snapshot includes production Java sources, runtime resources and Java test sources. Local build caches, runtime instances, worlds, logs, credentials, screenshots and development notes are excluded. Tests may require their own fixtures and runtime harness.
